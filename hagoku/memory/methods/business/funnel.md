# 漏斗分析指南

## 什么是漏斗分析

漏斗分析追踪用户从进入→转化过程中各阶段的转化率，识别流失最大的步骤。

## 典型漏斗阶段示例

```
访问首页 → 浏览商品 → 加入购物车 → 提交订单 → 支付完成
```

## 关键指标

| 指标 | 含义 |
|------|------|
| 阶段转化率 | 当前阶段人数 / 上一阶段人数 |
| 累计转化率 | 当前阶段人数 / 起始阶段人数 |
| 最大流失步骤 | 转化率下降最多的阶段 |

## 分析要点

1. **找瓶颈**：转化率断崖式下降的阶段是需要优化的点
2. **绝对值 vs 相对值**：大漏斗看绝对值，小漏斗看转化率
3. **分群对比**：新老用户、不同渠道的漏斗可能差异巨大

## 使用方式

调用 `funnel_analysis(stage_col='...' , stage_order=[...])` 自动计算各阶段转化率和最大流失步骤。
