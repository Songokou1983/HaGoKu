# 分析能力预设系统

## 概念

HaGoKu 的通道架构使得**切换提示词 = 切换分析领域**。不改代码，不改工具，只换一段 prompt，同一个分析引擎就能从"商业分析"变成"股市技术分析"或"电商运营分析"。

每个预设就是一段 system prompt，定义了：
- **角色**：用什么身份和用户对话
- **术语体系**：领域特定的词汇和分析框架
- **工具偏好**：在什么阶段优先使用什么工具
- **报告风格**：最终报告包含什么内容

## 使用

1. 打开侧边栏「分析能力」面板
2. 选择预设 → 点击「使用」
3. 之后所有分析自动按该方向执行
4. 标题栏会显示当前激活的预设名
5. 选「恢复默认」回到通用商业分析

## 新建预设

1. 点击「+ 新建场景」
2. 填写名称、图标、描述
3. 编辑提示词（可参考通用模板）
4. 点击「创建」

新建后立即可用。

## 模拟调试

每个预设卡片有「模拟」按钮，打开提示词实验室：

1. 编辑提示词
2. 输入测试消息
3. 试运行 → 看 LLM 回复
4. 对比原版 → 看工具调用差异
5. 满意后 → 保存为新场景

## 文件结构

```
hagoku/agents/
├── prompt.md              ← 默认提示词（通用商业分析）
└── presets/
    ├── presets.json        ← 预设元数据（名称/图标/描述）
    ├── general.md          ← 通用商业分析（与 prompt.md 一致）
    ├── stock.md            ← 股市技术分析
    ├── ecommerce.md        ← 电商运营分析
    └── {custom}.md         ← 用户自定义
```

## 激活机制

- 用户选择预设 → 写入 `~/.hagoku/active_preset`
- `agent._load_prompt()` 启动时优先读此文件
- 文件不存在或指向无效 ID → 回退 `prompt.md`
- 默认预设「通用商业分析」不可删除、不可修改
