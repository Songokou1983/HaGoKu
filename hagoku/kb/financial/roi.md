# ROI 分析框架

## 基本公式

```
ROI = (收益 - 成本) / 成本 × 100%
```

或

```
ROI = 收益 / 成本 - 1 × 100%
```

## 口径统一（最容易出错的地方）

| 项目 | 常见错误 | 正确做法 |
|------|---------|---------|
| 收益 | 混淆 GMV 和 净利润 | 用实际利润（扣除退款、退货、毛利） |
| 成本 | 只算广告费 | 包含广告费 + 人工 + 素材 + 平台抽成 |
| 时间窗口 | 用不同时间段 | 收益和成本必须同一周期（如投放后 30 天） |
| 归因 | 重复归因多个渠道 | 同一用户只归因一次 |

## 渠道 ROI 对比注意事项

1. **生命周期价值不同**：某个渠道客单价高，ROI 低但 LTV 高
2. **品牌效应**：直接转化低但对其他渠道有促进作用
3. **测试期 vs 稳定期**：新渠道测试期 ROI 波动大，需等数据稳定

## Python 示例

```python
import pandas as pd

df = pd.DataFrame({
    'channel': ['SEM', '信息流', 'KOL', 'SEO'],
    'cost': [50000, 30000, 80000, 10000],
    'revenue': [80000, 45000, 120000, 8000],
})

df['roi'] = (df['revenue'] - df['cost']) / df['cost']
df['roi_pct'] = df['roi'] * 100

# 排序看效果
print(df.sort_values('roi', ascending=False))
```
