# 异常值检测指南

## IQR 法（四分位距）

```
下界 = Q1 - 1.5 × IQR
上界 = Q3 + 1.5 × IQR
```

- 不依赖正态假设，对偏态分布鲁棒
- 适合：大多数业务数据（金额、用户数等常偏态）

## Z-score 法

```
Z = |x - mean| / std
异常：Z > 3（通常阈值）
```

- 假设数据近似正态分布
- 适合：正态分布数据、物理测量

## 方法选择

| 场景 | 推荐 |
|------|------|
| 数据偏态（金额、用户行为） | IQR |
| 数据正态（评分、温度） | Z-score |
| 不确定分布 | IQR（更保守） |

## 检测后的处理

- 极端但合理的数据（如 VIP 客户消费）→ 保留，分组分析
- 明显错误（如年龄=200）→ 清洗
- 边界 → 标注 + 敏感性分析（有/无差异）

## 使用方式

调用 `detect_outliers(method='iqr', columns=[...])` 检测指定列的异常值。
